# Vanta
Vanta is the public all-in-one Kruiger Labs Discord bot for music, moderation, verification, tickets, profiles, community management, games, giveaways, utilities and more.

## Primary command navigation
Vanta uses `/help` as its command/help panel. There is no requirement for a literal `/commands` command.

Major command families established in Vanta include `/music`, `/setup`, `/config`, `/automod`, `/giveaway`, `/serverstats`, `/birthdays`, `/invites`, `/voice`, `/guild`, and `/tickets`.

## Dashboard
The dashboard provides **Overview, Modules, Commands, General, Welcome & Leave, Music, Fun, Games, Tickets, Logs, Custom Voice, and Ticket Archives**.

Server managers can disable modules and individual commands. When a command/module is disabled, Vanta blocks it for that guild and directs the manager to the dashboard rather than silently failing.
