# Vanta Tickets & Applications
Vanta supports multi-panel tickets and application workflows.

## Ticket configuration
Ticket panels can use separate buttons, categories, support roles, labels/emojis, prefixes and welcome behavior.

## Applications
Established application commands are:

```text
/tickets application-create
/tickets application-post
/tickets application-list
```

The application flow uses an **Apply** button, a private modal, and a configured staff review channel.

## Ticket archives
The dashboard includes **Ticket Archives** and authenticated transcript access.

## Test before publishing
Create a ticket as a normal user, verify staff visibility, test close/archive/transcript behavior, and ensure users cannot see other private tickets.
