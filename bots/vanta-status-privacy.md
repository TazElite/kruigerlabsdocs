# Vanta Status, Data & Privacy
Vanta exposes public operational/status information while private guild configuration and ticket data belong behind authenticated access.

Public status can include bot state, uptime duration, Discord latency, server/member counts and music-session health. The published **99.9%** figure is an availability **target** unless historical monitoring actually measures it.

Ticket archives/transcripts are authenticated dashboard data. Public music/status pages should not expose private queue contents or guild IDs.

Profile visibility must respect public/private user choice.
