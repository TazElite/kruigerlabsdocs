# Vanta Getting Started
## 1 — Add Vanta
Use the official Vanta invite flow and select the Discord server you are authorized to manage.

## 2 — Check role position
Features that assign/manage roles require Vanta's bot role to be above the roles it must manage. Discord role hierarchy still applies even when a feature is configured correctly.

## 3 — Open `/help`
Use `/help` to explore Vanta's available command system.

## 4 — Configure the server
Use `/setup` workflows and/or the dashboard. Do not enable every module just because it exists. Enable what your community uses.

## 5 — Test as a non-admin
Administrators can bypass Discord restrictions that normal members experience. Test verification, tickets and role features using a normal test account.

## 6 — Configure logs
Use `/setup logs` and the dashboard/log settings for the events your staff actually need.

## 7 — Test restart/reconnect behavior
Verify panels, settings, roles and commands after a reconnect and after Vanta/server restarts.
