# Kruiger Labs Documentation

This repository is the content source for the public documentation at **kruigerlabs.xyz/docs**.

Documentation is organized as Markdown so guides can be added without redesigning the website. The Kruiger Labs website reads this repository server-side through GitHub. Keep secrets, customer files, license keys, database passwords, bot tokens, and private server configurations out of documentation.

## Content groups
- `fivem/` — general FiveM server guides
- `free/` — free Kruiger Labs resources
- `paid/` — paid Kruiger Labs resources
- `bots/` — public bot documentation
- `troubleshooting/` — cross-product troubleshooting
- `faq/` — frequently asked questions

## Adding a page
Copy an existing Markdown page, change the front matter, write the guide, and push to `main`. The website automatically discovers Markdown files from this repository.

## Affiliate links
Recommended-service pages may contain affiliate links. Keep the disclosure visible whenever an affiliate URL is used.
