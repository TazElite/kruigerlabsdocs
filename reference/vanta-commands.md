# Vanta Command-Family Reference
Vanta uses `/help` as the main command/help navigation.

Established families/workflows include:
- `/setup` — server setup, including verification and logs.
- `/config` — configuration, including auto replies.
- `/music` — music workflow.
- `/automod` — AutoMod.
- `/giveaway` — giveaways.
- `/serverstats` — server statistics.
- `/birthdays` — birthdays.
- `/invites` — invite features/logs.
- `/voice` — voice features.
- `/guild` — guild utilities, including backups.
- `/tickets` — ticket/application workflows.

Examples established in the current documentation include `/setup verification`, `/setup logs`, `/invites logs`, `/config autoreply-add`, `/config autoreply-list`, `/config autoreply-remove`, `/guild backup-create`, `/guild backup-list`, `/guild backup-restore`, `/tickets application-create`, `/tickets application-post`, and `/tickets application-list`.

Use `/help` and the current dashboard for the exact command set available in the deployed Vanta version.
