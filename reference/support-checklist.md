# Support Information Checklist
Include:
- product/resource/bot name
- installed version
- FXServer build or bot runtime version
- framework and relevant dependency versions
- exact error text
- first relevant console/log error with context
- expected behavior
- actual behavior
- exact reproduction steps
- whether it reproduces after a cold boot
- whether it affects all users
- screenshots/video when useful
- sanitized relevant configuration
- changes made immediately before the issue
- troubleshooting already attempted

Never send passwords, tokens, private keys, database credentials, license keys or full webhook URLs.


## Document status
