# FiveM Resource Release Checklist
- [ ] Version updated.
- [ ] Manifest metadata/dependencies correct.
- [ ] Fresh install tested.
- [ ] Upgrade from previous supported version tested.
- [ ] Cold boot tested.
- [ ] Multi-player behavior tested where relevant.
- [ ] Allowed/denied permissions tested.
- [ ] Client/server validation reviewed.
- [ ] Debug spam removed.
- [ ] Secrets/test credentials removed.
- [ ] README/install/config/update instructions current.
- [ ] Changelog written.
- [ ] Rollback/migration notes included when needed.


## Document status

**Last reviewed:** September 2026  
**Version note:** Use the instructions that match your installed product/resource version. When behavior differs from your release, check its release notes before changing production configuration.
