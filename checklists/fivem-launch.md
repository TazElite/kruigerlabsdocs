# FiveM Production Launch Checklist
- [ ] Current known-good backup exists.
- [ ] Database backup restore process is understood.
- [ ] Full cold boot completes without relevant errors.
- [ ] Required resources start in the intended order.
- [ ] Normal player can connect.
- [ ] Staff permissions tested.
- [ ] Unauthorized permission test completed.
- [ ] Database create/read/update path tested.
- [ ] Voice/chat/HUD/core gameplay tested.
- [ ] Logging destinations tested.
- [ ] Secrets are not in public repositories.
- [ ] Staging/current production versions recorded.
- [ ] Rollback steps documented.
- [ ] Maintenance/support contacts/process ready.
