# Vanta Server Setup Checklist
- [ ] Vanta added to the correct guild.
- [ ] Role hierarchy verified.
- [ ] Only required Discord permissions granted.
- [ ] Dashboard guild/settings verified.
- [ ] Modules/commands reviewed.
- [ ] Verification tested with a normal member.
- [ ] Ticket open/close/archive tested.
- [ ] Logs tested.
- [ ] Moderation/AutoMod tested safely.
- [ ] Profile/privacy behavior reviewed.
- [ ] Music tested if enabled.
- [ ] Backup workflow reviewed.
- [ ] Staff know where to use `/help` and where to get support.
