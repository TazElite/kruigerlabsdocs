A VPN can encrypt traffic between your device and the VPN provider and can be useful on untrusted networks. It does **not** replace MFA, strong passwords, server hardening, backups, or proper access control.

## NordPass — password manager

**Kruiger Labs NordPass link:**

NordPass is a **password manager, not a VPN**. Use a password manager to generate/store unique credentials rather than reusing one password across hosting, GitHub, Discord, email, databases, and panels.

## Recommended account-security baseline
1. Unique password for every administrative account.
2. MFA everywhere it is supported.
3. Password manager for credential storage.
4. Separate deployment credentials with minimum access.
5. Never share private keys or tokens in support screenshots.
6. Rotate a credential immediately if exposed.
