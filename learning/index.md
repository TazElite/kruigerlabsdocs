# Kruiger Labs Academy

The Academy is the guided side of Kruiger Labs Documentation. Pick the path closest to your goal and complete it in order. Every path points into the full documentation library, so you can branch into deeper reference material whenever you need it.

## How to use a path
1. Start with the prerequisite check.
2. Complete each lesson in order.
3. Do the success check before moving on.
4. Use the linked troubleshooting/reference material when something fails.
5. Finish the capstone instead of stopping after reading.

## Paths
- **FiveM From Zero** — player → server owner → first developer workflow.
- **First Production FiveM Server** — build, secure, test, back up and launch.
- **FiveM Developer** — Lua/resources/events/NUI/database/security/release.
- **Kruiger Ultimate Suite** — deploy and validate the paid FiveM suite.
- **Vanta Server Administrator** — permissions, dashboard, verification, tickets, logs and operations.
- **Git & Deployment** — source control, private repositories, staging, deployment and rollback.
- **Troubleshooting Technician** — reproduce, isolate, read logs and build useful support reports.

> A learning path is not a shortcut around prerequisites. If a lesson's success check fails, fix that layer before continuing.
