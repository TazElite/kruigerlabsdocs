# KruigerHUD

KruigerHUD is the main HUD package for Kruiger Labs FiveM servers.

## Postal map requirement
For HUD layouts that are designed to align with postals, use the Postal Map referenced by the product listing/documentation. A different map can cause visual/postal alignment differences.

## Installation
1. Install the resource as delivered.
2. Install documented map/dependency requirements.
3. Configure server/department display options.
4. Ensure dependencies before KruigerHUD.
5. Test at multiple resolutions before launch.

## Adding departments
Use the department configuration included in your release. Add the department identifier, display name, and any related presentation/permission values required by that version. Keep identifiers consistent with other Kruiger components when using the suite.

## Troubleshooting
For missing HUD elements, check NUI/client errors, resource start order, configuration syntax, and whether required assets/maps are running.
