# KruigerHeadtags

KruigerHeadtags provides configurable in-game headtags.

## Installation
Install the resource, configure tags/departments, configure the version's documented permissions, and ensure it after any dependency it requires.

## Adding headtags
Use the tag list in the configuration included with your version. Add a new unique tag/department entry and map it to the documented permission or group mechanism. Keep the display label and permission identifier distinct and readable.

## Permissions
If your version uses ACE, keep its ACE entries in `permissions.cfg` and load that file before testing.

## Troubleshooting
If the wrong tag appears, check overlapping permissions and the order/priority rules in the resource. If no tag appears, verify the player's permission/group and client console.
