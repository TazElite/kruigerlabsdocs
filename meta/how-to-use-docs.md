# How to Use Kruiger Labs Documentation
**Learning Paths** teach a subject in order. **Guides** explain one task deeply. **Reference** pages are fast lookups. **Error Encyclopedia** pages start from a symptom. **FAQ** answers common short questions.

For a new subject, start with a Learning Path. For a specific task, search the guide title. For an exact error, use the Error Encyclopedia.
