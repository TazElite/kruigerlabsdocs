# Documentation Versions & Updates
Product behavior can change between releases. Before changing production configuration, identify the installed product version and compare it with the documentation/release notes.

Never overwrite a working configuration with a new default file blindly. Back up, diff the schemas, migrate supported values, then test on staging where possible.


## Document status

**Last reviewed:** September 2026  
**Version note:** Use the instructions that match your installed product/resource version. When behavior differs from your release, check its release notes before changing production configuration.
