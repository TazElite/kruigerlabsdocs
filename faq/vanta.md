# Vanta FAQ
<details><summary><strong>Where is /commands?</strong></summary><p>Vanta's established help/command navigation uses <code>/help</code>.</p></details>
<details><summary><strong>Why does Vanta say a module is disabled?</strong></summary><p>The guild has that module disabled. A server manager can enable it in the dashboard.</p></details>
<details><summary><strong>Why can Vanta not assign my Verified role?</strong></summary><p>Check Manage Roles and move Vanta's bot role above the role it must manage.</p></details>
<details><summary><strong>How long does a verification link last?</strong></summary><p>The established web verification links expire after 5 minutes and are account-bound.</p></details>
<details><summary><strong>Are private profiles shown globally?</strong></summary><p>They should not be. The global directory is for public profiles.</p></details>
<details><summary><strong>Does a music failure mean Vanta is offline?</strong></summary><p>No. An individual provider or track can be unavailable while Vanta remains online.</p></details>
<details><summary><strong>Can I disable only one command?</strong></summary><p>Yes. Vanta's guild settings support module and individual command switches.</p></details>
