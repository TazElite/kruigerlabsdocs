# Frequently Asked Questions

<details>
<summary><strong>Do I need a framework for every Kruiger free script?</strong></summary>
<p>No. Several Kruiger utilities are designed to be standalone. Always check the specific product page for the version you are installing.</p>
</details>

<details>
<summary><strong>Can I put resources inside bracket folders?</strong></summary>
<p>Yes. Bracket folders such as <code>[kruiger]</code> are commonly used to organize complete resource folders.</p>
</details>

<details>
<summary><strong>Should all permissions stay in server.cfg?</strong></summary>
<p>They can, but a large server is often easier to manage with a dedicated <code>permissions.cfg</code> loaded by <code>exec permissions.cfg</code>.</p>
</details>

<details>
<summary><strong>Can I manage my FiveM server through GitHub or GitLab?</strong></summary>
<p>Yes. Git is useful for versioned configuration and code you are allowed to store. Keep credentials out of the repository and use restricted deployment credentials for private repositories.</p>
</details>

<details>
<summary><strong>Should my server automatically deploy every commit?</strong></summary>
<p>Not necessarily. Production servers are usually safer with a review/test step before the live server pulls a change.</p>
</details>

<details>
<summary><strong>Where do I get support?</strong></summary>
<p>Work through the relevant troubleshooting page first. If the issue remains, join <strong>discord.gg/kruigerlabs</strong> and provide the product/version, relevant error, and steps already tried.</p>
</details>
