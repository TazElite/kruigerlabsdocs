# Creating Your First Local FiveM Server

Go from no server to a working local FXServer using txAdmin.

## Download server artifacts

Use the official Cfx server download and choose the current recommended build. Extract the archive into a dedicated folder rather than mixing it with your FiveM client.

## Start txAdmin

Run `FXServer.exe` on Windows. txAdmin is bundled with FXServer and normally opens in your browser. If needed, its default local port is `40120`.

## Link and deploy

Enter the PIN shown by FXServer, link your Cfx account, register the server, choose a name, and use the **FiveM Basic Server (CFX Default)** recipe for a clean learning server.

## Registration key

Use the Cfx Portal link supplied by the deployer, generate the server registration key, return to txAdmin, and complete the recipe.

## Verify

Choose **Save and Run Server**, connect from FiveM on LAN, then open F8 and verify the server is responsive. Back up this clean baseline before adding scripts.
