# Performance & resmon
Add resources gradually and measure the server after meaningful changes.

## Practical workflow
1. Establish a stable baseline.
2. Add a small group of resources.
3. Test normal gameplay.
4. Use available FiveM profiling/resource-monitoring tools to identify unusual cost.
5. Remove or fix the actual offender instead of randomly increasing server resources.

## Streamed assets
Large vehicles, maps, clothing, and other assets can create different bottlenecks from script CPU. Diagnose the symptom before choosing a fix.

## Success check
You have a baseline and can identify which change introduced a performance regression.
