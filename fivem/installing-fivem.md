# Installing FiveM From Scratch

Download, install, sign in to, and verify the FiveM client on Windows.

## Before you start

Install and update a legitimate GTA V installation first. Make sure Windows and your graphics drivers are reasonably current, and create/sign in to your Cfx account.

## Step-by-step

1. Open the official FiveM website and choose **Download Client**.
2. Review the Cfx terms and continue if you agree.
3. Run `FiveM.exe` from Downloads.
4. When asked, select your GTA V installation (`GTA5.exe`).
5. Allow FiveM to prepare/update its game data.
6. Choose **Sign in with Cfx**, authorize in the browser, then return to FiveM.
7. Wait for the FiveM home screen to load.

## Success check

You should see your signed-in FiveM client and be able to browse servers. If installation fails, record the exact message before reinstalling anything.
