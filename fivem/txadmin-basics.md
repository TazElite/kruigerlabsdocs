# txAdmin Basics
txAdmin is the server-management interface bundled with FXServer.

## Initial setup
Follow the official Cfx setup flow to register the server, deploy a recipe, add your Cfx license key, and start the server.

## Daily workflow
Use txAdmin to watch server health/logs, manage controlled restarts, inspect players, and administer access according to the permissions you intentionally grant.

## Do not give everyone full access
Create staff access around responsibilities. Someone who only needs player moderation does not necessarily need console, configuration, or server-control access.

## Before changing production
Back up first, make one logical change, restart only what is necessary, read the console, then test in-game.

## Success check
You can start/stop the server, find the live console, identify a resource error, and restore a backup before proceeding with major customization.
