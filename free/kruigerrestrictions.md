# KruigerRestrictions

A configurable restrictions resource for servers that want class-based access rules.

## Features
- Vehicle restrictions.
- Weapon restrictions.
- Optional clothing restrictions.
- Class/group-oriented configuration.

## Installation

```cfg
ensure KruigerRestrictions
```

## Configuration
Use the configuration included with your release to define the classes/groups and restricted items. Test changes in a non-production environment before applying large restriction lists.

## Troubleshooting
If an item is incorrectly blocked, check spelling/model identifiers, the player's assigned class/group, and whether another permissions/restrictions resource is also enforcing access.
